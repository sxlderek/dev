# Skills

Published, generalized skills in this repo. Each lives in its own
subdirectory; all are sanitized (no PII, no secrets, no absolute paths) so they
are safe to reuse in any agent.

| Skill | Description |
|---|---|
| [ai-model-research](ai-model-research/) | Research AI models, parameter sizes, context windows, pricing, and agentic suitability. |
| [ai-provider-research](ai-provider-research/) | Research AI inference providers, verified pricing tables, capabilities, and privacy/ZDR policies. |
| [baby-girl-name](baby-girl-name/) | Generate cute, wholesome, brandable 8–12 letter social media usernames for baby-girl persona. |
| [cdn-checker](cdn-checker/) | Passive detection of CDN edge networks, WAF, bot challenges (Turnstile/CAPTCHA), and deep asset inspection. |
| [cheatsheet-maker](cheatsheet-maker/) | Research a topic or URL and save a one-page cheat sheet to a SilverBullet space, linked from the space index. |
| [chaturbate-payout](chaturbate-payout/) | Extract Chaturbate token history into a clean Google Sheet or TSV table. |
| [cli-install](cli-install/) | Generate verified, single-path Windows PowerShell installation scripts without fallbacks. |
| [docren](docren/) | Suggest structured filenames based on document content (PDF/Word) using vision, with searchable OCR conversion. |
| [football-fans-avatar](football-fans-avatar/) | Generate FIFA national football fan 2D cartoon avatars with Ghibli/Miyazaki styling and directional gaze. |
| [idocr](idocr/) | Multi-country identity document (national IDs, passports) OCR using vision models and image pre-processing. |
| [pet-tag-avatar](pet-tag-avatar/) | Generate 1:1 manga baby pet avatars wearing prominent rectangular silver name ID tags. |
| [picx](picx/) | PicX-style image hosting and management via GitHub API with CDN linking (jsDelivr, Statically). |
| [pwgen](pwgen/) | Generate a 17-character custom pattern password starting and ending with lowercase, with mixed case, digits, and underscores. |
| [selfcheck](selfcheck/) | System health diagnostic checking availability of required CLI tools, media libraries (ffmpeg, ImageMagick), and workspace hygiene. |
| [siliconflow-skill](siliconflow-skill/) | SiliconFlow API workflows for chat, image generation, TTS, and ASR audio transcription. |
| [skill-publish](skill-publish/) | Sanitize, generalize, and publish an agent skill to a public repo. |
| [stripchat-payout](stripchat-payout/) | Extract Stripchat token history into a clean Google Sheet or TSV table. |
| [whois](whois/) | Domain WHOIS, DNS records (A, AAAA, NS, MX, TXT/SPF/DMARC), SSL certificates, and web screenshots. |
| [yoursafe-transfer](yoursafe-transfer/) | Check Yoursafe balance and prepare SEPA transfers to a saved beneficiary. |
